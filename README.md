# freetoken 库

长期免费层大模型接口目录，给进阶用户（比如穷学生）用的免费 API 目录。

## 定位

- 前端（后做）从这里拉数据，用户自带 API key，浏览器直接调各家，某家额度不够自动切下一家，用户只管聊。
- key 只存在用户自己的浏览器里，不经过本站；对话内容也不经过本站。

## 收录标准

- 只收长期免费层，短期试用不进。
- 公开可申请，申请流程和接口通断都实测过。
- 库里只有公开元数据（接口地址、免费模型、免费额度、申请链接和步骤、国内可用性），不含任何真实密钥。

## 数据文件

- `providers.json`：免费源列表（首批采集中，调研结果回来后写入）。

## 维护

免费政策变了就更新，死了的源标 stale，新的源验过再进。
