# freeoneapi

One API 的免费版：只走免费源的统一 API。项目包含两部分：免费源目录（本仓 `providers.json`）和本地网关（`gateway/`，单文件 Node，零依赖）。

与 One API 无关、独立实现。key 始终是用户自己的，网关只跑在用户自己的电脑上。

本地网关用法见 `gateway/README.md`，设计见 `DESIGN.md`。

长期免费层大模型接口目录；本地网关按库自动切换免费源。

## 定位

- 库（`providers.json`）：长期免费层大模型接口目录，只放公开元数据，不含任何真实密钥。
- 本地网关（`gateway/`）：在自己电脑上跑，OpenAI 兼容接口，某家额度不够自动切下一家免费源。
- key 只存在用户自己的电脑上；请求从用户电脑直接发往各家接口，不经过本站的中转服务器。

## 收录标准

- 只收长期免费层，短期试用不进。
- 公开可申请，申请流程以官方文档为准；接口通断待实测（见核实说明）。
- 库里只有公开元数据（接口地址、免费模型、免费额度、申请链接和步骤、国内可用性），不含任何真实密钥。

## 数据文件

- `providers.json`：免费源列表（v1，2026-11-03，官方文档核实版）。

## v1 入库（5 家）

- 国外：Google AI Studio（Gemini）、Groq、OpenRouter（:free 模型，名单动态过滤）
- 国内：SiliconFlow 硅基流动、智谱 BigModel（GLM）

## v1 未收录（原因）

- Hugging Face Inference Providers：免费账号月度额度 2026-10-07 起为 None，无免费层。
- Mistral La Plateforme：官方定价页对话模型全部标价，仅审核模型免费。
- Together AI：官方定价页无免费层，需先购额度。
- 阿里云百炼 DashScope：新人每模型 100 万 Token、90 天有效，是一次性试用金，不是长期免费层。
- DeepSeek：无免费层，按量付费（短问答约 ¥0.003–0.01/问），不是免费，v1 不收。

## 核实说明

- v1 是官方文档核实版：免费层以各家官方定价/文档页为准；`base_url_verified` 为 false 的地址待核官方 quickstart，不写成已核实。
- 实测（真正申请 key 并调通）为第二步；国内源的实名申请流程需本人手机/实名，待本人实测。

## 维护

免费政策变了就更新，失效的源标 stale，新的源验过再进。
